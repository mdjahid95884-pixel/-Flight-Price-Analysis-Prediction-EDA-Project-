# -Flight-Price-Analysis-Prediction-EDA-Project-
Exploratory Data Analysis on the Flight dataset using Python

#🛠️ Tools & Libraries Used

Python
Pandas
NumPy – numerical operations
Matplotlib & Seaborn – data visualization
Scikit-learn – preprocessing & train-test split

✅ Conclusion
This project demonstrates a complete data analytics workflow, from raw data cleaning to multivariate analysis and ML preparation.
It highlights how flight prices are influenced by a combination of airline choice, route, duration, and number of stops, making it suitable for real-world analytical and predictive applications.
